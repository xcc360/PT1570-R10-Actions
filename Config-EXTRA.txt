# 用户软件包基线：沿用 HG5585F-CT 那 6 个包
# 由 customize.sh 第 5 步自动追加到 .config；workflow 的 Configure 步骤会在
# 最终 make defconfig 之后硬断言这 6 个包全部 =y，缺失即失败，
# 避免编出"看似成功但少了插件"的固件。
#
# ⚠️ 与 HG5585F-CT 的关键差异（2026-11-09 核实）：
#    HG5585F-CT 用 pbs05/ponwrt，feeds 是 immortalwrt/packages + immortalwrt/luci，
#    6 个包全都现成。本仓库用 lyq1996/rtl9617c-openwrt，feeds.conf.default
#    指向官方 git.openwrt.org：
#      ✅ 官方已有：tailscale、luci-app-tailscale-community、其 zh-cn i18n
#      ❌ 官方没有：vlmcsd、luci-app-vlmcsd、其 zh-cn i18n
#    workflow 的 "Update and install feeds" 会从 immortalwrt 上游只取这两个
#    包目录，注入已拉取的官方 feeds（不追加 src-git、不让同名包覆盖官方版本），
#    再 feeds install -a 统一扫描。请勿删除该步骤，否则下面 3 个 =y 会被
#    make defconfig 静默丢弃，并触发 Configure 的 6 包硬断言失败。

# ---- tailscale ----
CONFIG_PACKAGE_tailscale=y
CONFIG_PACKAGE_luci-app-tailscale-community=y
CONFIG_PACKAGE_luci-i18n-tailscale-community-zh-cn=y

# ---- vlmcsd (KMS) ----
CONFIG_PACKAGE_vlmcsd=y
CONFIG_PACKAGE_luci-app-vlmcsd=y
CONFIG_PACKAGE_luci-i18n-vlmcsd-zh-cn=y

# ---- 6 包正常工作所必需的配套 ----
# tailscale Makefile: DEPENDS:=$(GO_ARCH_DEPENDS) +ca-bundle +kmod-tun
CONFIG_PACKAGE_kmod-tun=y
# 让 luci.mk 生成 zh-cn 的 luci-i18n-* 包。若该符号在本源码树不存在，
# make defconfig 会安全丢弃，i18n 仍按 LuCI 默认语言集生成。
CONFIG_LUCI_LANG_zh_Hans=y
