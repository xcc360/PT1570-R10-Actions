# PT1500-H10 2.5G（youhua,pt1500-h10-2p5g）独立云编译配置基线。
#
# 用户要求「软件包沿用 R10 那套」：本文件与 R10 的
#   Config-PT1570-FIT.txt + Config-EXTRA.txt
# 保持同一基线（北大镜像 apk 源 / 公钥 / argon / 中文 LuCI / tailscale 三件套），
# 唯一差异是本机 2.5G 版无 WiFi：
#   * 不带 kmod-rtl-ax-ap / wpad-* / wifi-scripts / wireless-regdb；
#   * 上游 youhua_pt1500_h10_2p5g 的 DEVICE_PACKAGES 本来也不含这些，
#     强写进去反而会被 make defconfig 丢弃或引入无用依赖。
#
# 后期与 R10 合并时：把「target / PON / LuCI / 时区 / tailscale」公共段抽成
# Config-COMMON.txt，两边各留机型段即可；独立期不改动 R10 的任何文件。
#
# 机型符号 CONFIG_TARGET_*_DEVICE_youhua_pt1500_h10_2p5g=y 与
# CONFIG_TARGET_PROFILE 由 customize-h10.sh 写入，不在这里硬编码。
# .config 会在 Configure 步骤里经历多次 make defconfig，未被 profile 点名的包
# 会被静默丢弃，workflow 会重新断言关键包。
